# Faith Mmaleatupa Ramatsakane - CV Website

A responsive, semantic HTML CV website built from scratch to showcase professional experience, skills, qualifications, and projects.  
This project emphasizes **semantic markup**, **accessibility**, and **clean design**.

---

##  Features

- **Semantic HTML5 structure**: `header`, `nav`, `main`, `section`, `article`, `footer`
- **Accessible navigation**: ARIA roles and labels
- **Profile image with caption**: `<figure>` + `<figcaption>`
- **Contact details & references**: `<address>` with clickable email and phone links
- **Professional summary, skills, qualifications, and projects** sections
- **Accessible contact form**: `<fieldset>`, `<legend>`, labels tied to inputs, `aria-required`
- **Responsive design**: styled with CSS, adaptable to different screen sizes
