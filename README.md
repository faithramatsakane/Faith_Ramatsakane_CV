# Faith Mmaleatupa Ramatsakane - CV Website

A responsive and interactive CV website built using **HTML5, CSS3, and JavaScript** to showcase professional experience, technical skills, qualifications, and projects.

This project emphasizes:

* Semantic HTML structure
* Accessibility best practices
* Responsive web design
* JavaScript API integration
* Geolocation and live weather functionality

---

## Features

### Semantic & Accessible Design

* Semantic HTML5 structure:

  * `<header>`
  * `<nav>`
  * `<main>`
  * `<section>`
  * `<article>`
  * `<footer>`

* Accessible navigation with ARIA labels

* Profile image using `<figure>` and `<figcaption>`

* Accessible contact form with:

  * `<fieldset>`
  * `<legend>`
  * Proper labels
  * `aria-required`

---

## Interactive Features

### Live Location & Weather

The website automatically:

* Detects the visitor’s location using the browser Geolocation API
* Fetches live weather data using the OpenWeatherMap API
* Displays:

  * Current city and country
  * Temperature
  * Weather description
  * Weather icon
  * Current date and time

---

## Responsive Design

The website is fully responsive and adapts to:

* Desktop screens
* Tablets
* Mobile devices

Responsive behavior is implemented using CSS media queries.
